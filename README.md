# 豆格 · 拼豆图纸生成器

一个完全在浏览器本地运行的图片转拼豆图纸工具。图片不会上传到服务器。

## 本地部署

项目自带一个只使用 Node.js 内置模块的静态服务器，无需执行 `npm install`。

Windows 用户可以直接双击 `start-local.bat`。服务器启动后，在浏览器打开：

<http://localhost:4173>

也可以在项目目录中手动启动：

```powershell
node server.js
```

服务器默认允许同一局域网中的设备访问。启动窗口会列出类似 `http://192.168.1.20:4173` 的地址；让手机或另一台电脑连接同一个路由器后，打开该地址即可。请只在可信的家庭或专用网络运行；Windows 首次询问防火墙权限时，只允许“专用网络”，不要在公共网络放行。

如需更换端口，可在 PowerShell 中运行：

```powershell
$env:PORT=8080; node server.js
```

## 以后迁移到树莓派

将项目复制或克隆到树莓派，安装 Node.js 后，在项目目录运行：

```bash
node server.js
```

也可以执行 `chmod +x start-local.sh` 后运行 `./start-local.sh`。服务器同样会显示局域网访问地址。需要长期全天运行、绑定域名或开放公网访问时，再配置 systemd 自动启动以及 Caddy/Nginx 的 HTTPS 反向代理即可；这些不影响当前项目代码。

GitHub 仓库现在只用于保存和同步代码，不再包含 GitHub Pages 自动发布工作流。

## 功能

支持分别设置横向与纵向网格数（默认 80 × 40），并可直接输入 4–64 的颜色数量上限。程序不会先压缩图片，而是让原图中的每个像素归入对应网格，并以区域全部像素的平均值作为格子颜色，再对相近颜色进行聚类。

默认使用带 MARD 色号的方格图纸，并在四周显示行列坐标。可将红色定位边界设置为每 5 格或每 10 格，也可选择实线或虚线。

图纸固定采用完整方格，并支持细网格线、色号、近白背景过滤、原图参考底图、手动画笔、画面取色、自定义颜色、撤销，以及高清 PNG 图纸和 CSV 用量清单导出。手动修改后，配色清单及豆子数量会实时更新。参考底图只用于编辑对照，不会出现在导出的图纸中。导出的 PNG 自带作品标题、图纸尺寸、颜色数、总豆数和完整的底部配色图例。

手绘内容使用独立覆盖层保存。切换近白背景、颜色数量和显示选项时不会丢失；调整网格尺寸时会按相对位置迁移到新网格。

配色清单中的每个颜色都带有整色替换按钮。可以选择任意 MARD 221 色号，一次替换图纸中所有相同颜色的格子；替换结果会参与数量合并、手绘、PNG/CSV 导出和撤销，并在自动参数重新计算后继续保留。

“无豆 / 留空”是一种独立于白色豆子的特殊状态。可以在手绘模式中作为橡皮逐格使用，也可以在整色替换中将某个色号的全部格子批量设为留空；留空格不会计入豆子总数、颜色数或导出配色清单。

橡皮是可切换状态：第一次点击会保存当前画笔颜色并进入留空模式，再次点击会退出橡皮并恢复之前使用的颜色。

## MARD 色板

自动转换结果会匹配到 MARD 221 色板，图纸、配色清单和 CSV 均显示实际 MARD 色号。手动画笔可直接从全部 221 个色号中选择。

色板数据来自 [bitbead.app palettes.json](https://github.com/pomodiary/bitbead.app/blob/main/data/palettes.json)，依照 CC BY 4.0 使用。
