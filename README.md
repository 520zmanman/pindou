# 豆格 · 拼豆图纸生成器

一个完全在浏览器本地运行的图片转拼豆图纸工具。图片不会上传到服务器。

## 本地部署

项目自带一个只使用 Node.js 内置模块的服务器，无需执行 `npm install`。账号功能使用 Node.js 内置 SQLite，建议使用 Node.js 24 或更新版本。

Windows 用户可以直接双击 `start-local.bat`。服务器启动后，在浏览器打开：

<http://localhost:4173>

也可以在项目目录中手动启动：

```powershell
node server.js
```

服务器默认允许同一局域网中的设备访问。启动窗口会列出类似 `http://192.168.1.20:4173` 的地址；让手机或另一台电脑连接同一个路由器后，打开该地址即可。请只在可信的家庭或专用网络运行；Windows 首次询问防火墙权限时，只允许“专用网络”，不要在公共网络放行。

需要暂时通过固定的免费公网地址访问时，可以为豆格注册一个独立的 ngrok 免费账户，并按照 [NGROK_SETUP.md](./NGROK_SETUP.md) 完成配置。项目提供 `configure-ngrok.bat` 和 `start-public-ngrok.bat`，其客户端、Authtoken 与日志均保存在 Git 忽略的 `data/` 目录，不会影响 OpenClaw 的 ngrok 配置。

服务器会自动使用 Brotli 或 gzip 压缩 HTML、CSS 和 JavaScript。带 `?v=...` 版本参数的静态资源会在浏览器中长期缓存，HTML 则始终重新验证；修改前端文件时，需要同步更新 `index.html` 中对应资源的版本参数。账号、草稿、支付等 `/api/` 响应继续使用 `no-store`，不会进入公共缓存。

如需更换端口，可在 PowerShell 中运行：

```powershell
$env:PORT=8080; node server.js
```

## 以后迁移到树莓派

将项目复制或克隆到树莓派，安装 Node.js 后，在项目目录运行：

```bash
node server.js
```

也可以执行 `chmod +x start-local.sh` 后运行 `./start-local.sh`。服务器同样会显示局域网访问地址。需要长期全天运行、绑定域名或开放公网访问时，再配置 systemd 自动启动以及 Caddy/Nginx 的 HTTPS 反向代理即可；这些不影响当前项目代码。

GitHub 仓库现在只用于保存和同步代码，不再包含 GitHub Pages 自动发布工作流。

## 功能

支持分别设置横向与纵向网格数（默认 80 × 40），并可直接输入 4–64 的颜色数量上限。程序不会先压缩图片，而是让原图中的每个像素归入对应网格，并以区域全部像素的平均值作为格子颜色，再对相近颜色进行聚类。

默认使用带 MARD 色号的方格图纸，并在四周显示行列坐标。可将红色定位边界设置为每 5 格或每 10 格，也可选择实线或虚线。

图纸固定采用完整方格，网格尺寸支持 8 × 8 至 600 × 600。编辑器支持拖拽、缩放、画笔、橡皮、取色、区域填充、路径预览、实心矩形和矩形选区，提供复制、剪切、粘贴、删除、取消、撤销/恢复。MARD 色板已扩展到291色，按A–H、M、P、Q、R、T、Y、ZG系列分类，支持勾选、搜索、全选、清空、JSON导入/导出、取消及保存应用。豆库记录各色库存数量，当前保存在本地浏览器；色板选择跟随草稿保存。来源与逐色差异见PALETTE_SOURCES.md。

支持最多20个手绘图层及独立转换底层，新建、复制、重命名、排序、显示/隐藏、锁定、清空、删除可使用撤销/恢复。旧版单层草稿自动迁移。留空仍代表最终位置不放豆，清空图层则恢复显示下层。多图层随本地/账号草稿保存，服务器草稿仍有12 MB限制。

画廊支持游客浏览缩略图、登录用户打开/分享作品、本人隐藏/删除及管理员下架；每账号最多20件，每小时最多10次分享。只保存合成后的图纸，不上传原始照片、隐藏图层及账号信息。PDF继续经过现有付费模块；作者收益、分成及专门画廊收费尚未启用。公开分享前需确认权利；管理员应在正式公网开放前制定内容审核与投诉流程。

左侧图纸设置统一控制实时预览与PDF，粗线间隔2–20格，支持粗细线颜色、线型及色号显示。缩小到每格不足8屏幕像素时预览暂不绘制色号以降低卡顿，放大后恢复；PDF不受影响。测试：`npm run test:editor`、`npm run test:gallery`。画廊测试使用内存数据库，不接触真实账号。

大尺寸图纸的手绘工具栏会固定在绘制区顶部，纵向或横向滚动画布时仍可操作。绘制区支持 25%–300% 缩放、恢复 100%、适合宽度以及 `Ctrl + 鼠标滚轮` 缩放；放大时会按当前倍率重新进行高清绘制，不再拉伸低分辨率画面。缩放后的手绘坐标会按画布实际显示比例换算，不影响原始网格数据或导出分辨率。

手绘内容使用独立覆盖层保存。切换近白背景、颜色数量和显示选项时不会丢失；调整网格尺寸时会按相对位置迁移到新网格。

配色清单中的每个颜色都带有整色替换按钮。可以选择任意 MARD 221 色号，一次替换图纸中所有相同颜色的格子；替换结果会参与数量合并、手绘、PNG/CSV 导出和撤销，并在自动参数重新计算后继续保留。

“无豆 / 留空”是一种独立于白色豆子的特殊状态。可以在手绘模式中作为橡皮逐格使用，也可以在整色替换中将某个色号的全部格子批量设为留空；留空格不会计入豆子总数、颜色数或导出配色清单。

橡皮是可切换状态：第一次点击会保存当前画笔颜色并进入留空模式，再次点击会退出橡皮并恢复之前使用的颜色。

当前版本支持在浏览器 IndexedDB 中自动保存一份本地草稿，内容包括原图、网格参数、显示选项、手绘覆盖和整色替换。草稿在最后一次编辑或手动保存后保留 3 天，再次打开同一浏览器地址时会自动恢复；过期草稿会在下次打开页面时清理。未登录时该缓存不会上传，也不会在不同设备、浏览器或不同网站地址之间同步。

## 账号与付费基础

服务器已经加入用户名和密码注册、登录、退出以及登录状态恢复。密码使用随机盐和 `scrypt` 哈希保存，登录 Cookie 设置为 HttpOnly；账号数据库位于本地 `data/pindou.db`，该目录已被 Git 忽略，不会被提交到仓库。

登录后，原图和项目编辑数据会自动同步为账号云草稿。每个账号只保留一份、单份最多 12 MB，最后一次保存 3 天后由服务器定时清理；在其他设备登录同一账号后可以手动恢复该草稿。

数据库同时包含邮箱验证、验证问题、账户余额、充值订单、下载记录和公开分享作品的数据表。账号可使用 10 分钟邮箱验证码找回密码，也可在登录后设置验证问题作为备用找回方式；验证问题答案以随机盐和 `scrypt` 哈希保存，不保存明文。手机注册、绑定和短信找回入口目前已隐藏，服务端仅保留以后接入付费短信服务所需的兼容代码。配置方法见 [AUTH_RECOVERY_SETUP.md](./AUTH_RECOVERY_SETUP.md)。

新账号现在必须先完成真实邮箱验证码验证后才能注册；Windows 用户可双击 `configure-email.bat`，将 SMTP 邮箱和客户端授权码保存在不会上传 GitHub 的 `data/smtp-config.json` 中。配置完成并重启服务后，注册邮件与邮箱找回密码会使用真实邮箱发送。用户登录后可在账号窗口设置或更换验证问题，设置时必须再次输入当前密码。

网页顶部提供“用户反馈”入口，游客和登录用户均可提交建议。反馈内容通过服务器 SMTP 直接发送给站点管理员，默认收件地址为 `SMTP_FROM`，也可使用 `FEEDBACK_TO` 单独指定；同一来源 30 分钟最多发送 3 次。

下载价格由服务器统一返回：未登录游客下载自己的 PDF 为 20 分（0.20 元），已注册并登录的会员账户为 10 分（0.10 元），超级测试账户免费；平台共享图纸仍预留为每次 1 分（0.01 元）。前端显示不会自行决定最终金额，实际支付下单时必须再次以服务器价格创建订单。

游客和登录账户现可先使用赞赏码截图校验试用：订单创建后的前 2 分钟用于支付，之后另有 5 分钟上传清晰显示付款金额和时间的支付成功截图。付款校验通过或余额扣款成功后，会获得 2 分钟可重复下载 PDF 的限时权限；刷新或重新进入网站不会重复收费。登录账户也可充值 1.00–500.00 元后使用余额支付；充值订单金额必须与截图中的付款金额完全一致，否则系统不会自动入账，并引导用户通过反馈窗口上传付款截图和证据等待管理员处理。每次正常充值、扣款都会写入对应账号的钱包流水。服务器会阻止同一截图在游客与账户订单间重复使用。该模式仍不能向微信确认真实到账，截图也可能伪造，只用于接入微信支付商户 API 前的短期测试。配置方法见 [REWARD_CODE_SETUP.md](./REWARD_CODE_SETUP.md)。

高清图纸已经可以封装为大幅面 PDF，并接入统一结算入口：单张图纸页最多容纳 160 × 160 格，保留全局行列坐标、MARD 色号和红色分区线，末页附完整配色清单。160 × 160 会生成 1 张大幅面图纸页和 1 张配色页；图纸页不会压缩到 A4 尺寸，放大查看时可保持清晰，打印时可在 PDF 阅读器中使用“海报/平铺”模式拆分到多张 A4。游客与登录用户都不能直接免费下载；登录用户可选择余额支付或赞赏码单次支付。以后取得微信支付商户资料后，应将截图试用流程替换为 Native 下单、回调验签和服务端下载凭证。配置要求见 [WECHATPAY_SETUP.md](./WECHATPAY_SETUP.md)。CSV 用量清单暂时仍可免费导出。

### 超级测试账户

超级账户拥有独立的 `superuser` 角色，可免费执行 PDF 下载以及后续加入的收费功能，不扣除余额。不要在源码中写死密码；使用下面的工具生成随机强密码：

```powershell
node scripts/create-superuser.js douge_super_test --generate
```

工具只显示一次随机密码，数据库仅保存 `scrypt` 哈希。若同名账号已经存在，默认只升级角色而不修改原密码；需要重置时追加 `--reset-password`。正式公开网站前应重新生成密码或将测试账号降级/删除。

## MARD 色板

自动转换结果会匹配到 MARD 221 色板，图纸、配色清单和 CSV 均显示实际 MARD 色号。手动画笔可直接从全部 221 个色号中选择。

色板数据来自 [bitbead.app palettes.json](https://github.com/pomodiary/bitbead.app/blob/main/data/palettes.json)，依照 CC BY 4.0 使用。
